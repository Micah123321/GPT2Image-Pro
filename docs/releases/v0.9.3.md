# GPT2Image Pro v0.9.3

本版将 ChatGPT Web 出口代理升级为多上游池：进程内健康探测与自动故障转移。

## 新增

- **chatgpt-web-proxy 多上游出口池**：`CHATGPT_WEB_UPSTREAM_POOL` 配置
  逗号分隔的 socks5 出口（按优先级），每 60 秒以与业务一致的 TLS 指纹
  探测各出口，当前出口连续 3 次失败自动切换到健康备胎；切换时作废
  绑定旧出口的会话与 cf_clearance。`/healthz` 暴露池状态。
- **向后兼容**：未配置 POOL 回落旧单上游变量，均不配置直连，存量部署
  行为不变；clearance 代理默认跟随当前生效出口。
- **部署指引**：README 新增出口代理章节（WARP sidecar 片段、跨服务器
  第二出口部署三步、健康观测方式）。

## 升级说明

- 本版本不包含数据库迁移。
- 建议为 ChatGPT Web 后端配置至少两个不同网络路径的出口；同机多 WARP
  出口 IP 相同，无轮换价值。

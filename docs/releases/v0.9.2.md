# GPT2Image Pro v0.9.2

本版引入按质量档位的差异化计价与 API 出站模型映射，并统一账单明细与
创作页报价的计算口径展示。

## 新增

- **API 出站模型映射**：自定义 API 与池 API 可配置「本站型号 → 上游型号」
  规则表，支持按请求 quality 分档命中，提供 Adobe GPT Image / Gemini
  渠道预设；命中后可同时改写出站 quality。
- **质量计价倍率**：池 API 与 ChatGPT 账号（web/codex）均可按质量档位
  （auto/low/medium/high/xhigh/max）配置计费倍率；折入总倍率后贯通
  预扣、轮次、结算与退款，账单留痕质量分量便于对账。未配置档位按
  1 倍计，xhigh/max 未单独配置时回退 high 档。
- **报价与明细公式化**：历史记录展示倍率前基础/审核积分与「计费倍率」；
  创作页四处预估展示「（基础 + 审核）× 分组倍率 × 质量倍率」完整公式，
  切换质量即时联动。

## 修复

- **换号调度**：同优先级换号预算用尽后进入下一优先级档并钉住已用尽档；
  无图输出上限按整次请求累计，不随换档清零。

## 升级说明

- **包含数据库迁移 0048**：`image_backend_api` / `image_backend_account`
  新增 `quality_billing` json 列（幂等，可重复执行）。升级时先迁移再切流。
- 未配置质量倍率的部署计费行为与 v0.9.1 完全一致，可安全升级。
